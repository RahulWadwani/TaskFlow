# TaskFlow
Taskflow is a streamlined, intuitive web application designed to optimize project management and daily task execution, built for high performance and seamless team collaboration.

Features
Unified Dashboard: Real-time visibility into project health, upcoming deadlines, and assigned daily priorities.

Task Lifecycle Management: Granular creation, assignment, status tracking, and categorization via flexible Kanban and list views.

Collaboration Engine: Inline commenting and activity feeds to keep all project communications contextual.

Workflow Automation: Automated status triggers and dependency management to eliminate administrative bottlenecks.

Tech Stack
Frontend: HTML, Javascript and CSS

Backend: Python/FastAPI

Database & Backend-as-a-Service: PostgreSQL hosted on Supabase (leveraging Supabase Auth, Row Level Security, and real-time database capabilities)
